# АИСПВИ — фронтенд (модуль вкладов)

React + TypeScript + [Vite](https://vitejs.dev/). Запросы к API идут через **прокси Vite** на `http://127.0.0.1:8000`, поэтому в браузере не нужен CORS.

## Требования

- Node.js 20+ (или 18 LTS)
- Запущенный бэкенд: из папки `PythonAPI` выполните `uvicorn app.main:app --reload`

## Установка и запуск (VS Code)

1. Откройте папку `front` в VS Code (**File → Open Folder**).
2. Терминал: `npm install`
3. Терминал: `npm run dev`
4. В браузере откройте адрес из вывода (обычно `http://127.0.0.1:5173`).

## Сборка для продакшена

```bash
npm run build
npm run preview
```

Для продакшена без прокси настройте `VITE_API_BASE` или разместите фронт и API за одним доменом и включите CORS на FastAPI.

## Данные из банков

Каталог вкладов заполняется из **открытых API банков** (без демо-сида). При старте бэкенда выполняется первая синхронизация; в интерфейсе кнопка **«Обновить каталог»** вызывает `POST /api/v1/sync/live-deposits/`.

Сейчас в бэкенде подключён публичный API **Беларусбанка**; другие банки добавляются в `app/services/live_sync_all.py`, когда есть стабильный публичный endpoint.
